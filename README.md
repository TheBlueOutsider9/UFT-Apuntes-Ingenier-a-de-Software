UFT Apuntes: Plataforma Colaborativa Estudiantil

Descripción del Proyecto

UFT Apuntes es el diseño, planificación y modelado de una plataforma web colaborativa orientada a la comunidad de la Universidad Finis Terrae. Su objetivo principal es permitir a estudiantes, exalumnos y docentes subir, buscar, descargar y validar apuntes académicos de forma centralizada.

Este proyecto aborda la necesidad de tener acceso rápido y confiable a material de estudio complementario, superando las limitaciones de las plataformas institucionales tradicionales al fomentar el aprendizaje autónomo y colaborativo.

Características Principales

Gestión de Materiales: Carga de documentos (PDF, DOCX) clasificados por facultad, carrera y asignatura.

Búsqueda Avanzada: Filtros dinámicos para encontrar recursos específicos rápidamente.

Interacción y Comunidad: Sistema de "Favoritos" para guardado personal y perfiles de usuario.

Sistema de Moderación: Control de acceso basado en roles (RBAC). Los coordinadores de carrera validan y aprueban el material antes de que sea público.

Arquitectura y Modelado

El sistema fue planificado bajo estándares formales de Ingeniería de Software:

Arquitectura: Diseño Cliente-Servidor estructurado en 3 capas (Frontend, Backend, Persistencia).

Metodología: Uso del modelo ágil RAD (Rapid Application Development) para iteraciones rápidas y entregas de valor continuo.

Requisitos: Especificación formal bajo la norma ISO/IEC/IEEE 29148.

UML: Modelado del sistema mediante diagramas de Casos de Uso, Secuencia y Componentes.

Tecnologías Proyectadas

El diseño sugiere el siguiente stack tecnológico para su implementación:

Frontend: React (HTML5, CSS3, JavaScript).

Backend: Node.js (Express) o PHP (Laravel) gestionando APIs RESTful.

Base de Datos: PostgreSQL o MySQL.

Gestión del Proyecto

La planificación incluyó estimación de esfuerzo mediante el método Wideband Delphi, estructuración de tareas (WBS) y visualización en Carta Gantt.
